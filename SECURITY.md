# Security

`spec3 correction` works with live camera video, so privacy and local control are important.

## Supported Versions

The main branch is the active development line.

## Reporting A Security Issue

Please open a private report through GitHub security advisories if available, or contact the repository owner directly.

Do not include private camera recordings, personal documents, meeting links, access tokens, or local databases in public issues.

## Camera Data

The app is designed to process camera frames locally. Project documentation, issues, and pull requests should not include personal recordings unless they are intentionally shared and scrubbed of private information.
